# keycraft interface

The React interface and keyboard visualization for keycraft.

See the [project README](../README.md) for setup, imports, and packaging.

```sh
yarn install --frozen-lockfile --ignore-optional
npm start
npm run build
npm test -- --watchAll=false --runInBand
```

`npm start` opens a UI preview on port 3090. Use `npm run desktop` from the repository root to run the app and test Vim and tmux imports.
